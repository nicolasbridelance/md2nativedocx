# Non-technical guide — no code required

This page doesn't talk about code. It explains what this tool does, why, and how to use it if
you're not a developer.

## The problem, in one sentence

A "Mermaid" diagram (a flowchart, an architecture sketch...) written by a developer or an AI is
structured text that's very efficient to produce and evolve — but unreadable as-is for most
business, legal, or client reviewers. Until now, the only way to make it readable in a Word
document was to turn it into a **frozen image**: no shape is editable anymore, you can't move a
step, fix a label, or change a color without asking the developer to regenerate the whole thing.

## What `md2nativedocx` does

It converts a Markdown document (text, headings, tables) containing Mermaid diagrams into a real
**Word file (`.docx`)**, where every shape in the diagram is a **native Word shape** — exactly as
if someone had drawn it by hand with Word's own drawing tools. Concretely, in the document you
receive, you can:

- click a box in the diagram and select it individually;
- fix text directly inside the shape, without leaving Word;
- move a step, change a color, resize it — like any Word shape;
- copy the diagram into another document, a PowerPoint, an email.

None of this is possible with a PNG image — that's the difference this tool brings.

## How to use it, without installing any developer tool

**Most common case: someone already sends you the `.docx`.** You don't need to install anything —
open the file in Word as usual, everything works like a normal Word document.

**If you want to produce the `.docx` yourself** from a Markdown document (say, one received from
a colleague or generated by an AI):

1. Install the **md2nativedocx** extension in Visual Studio Code (free, like a word processor).
2. Open the `.md` file containing the diagram.
3. An **"⚙️ Export to Word"** link automatically appears above every detected diagram — no
   command to remember.
4. Click it: a notification offers to open the generated `.docx` directly in Word, or to locate
   it in the file explorer.

That's it — no command line, no configuration.

## "What if I have an AI do this work?"

That's the use case this tool is built for. An AI reasons and writes considerably better — faster,
more reliably, easier to correct — in Markdown/Mermaid than trying to directly produce a verbose
`.docx` phrase by phrase. So you can ask an AI to draft a report or an architecture diagram in
Markdown, then get a real, clean Word document in one click, without ever having to read or write
Markdown yourself: the tool is the bridge, not an extra skill to learn.

## Frequently asked questions

**Does my content get sent to an external server?**
No. Everything happens on your own machine. See [`legal.md`](legal.md) for the detail of the
(rare) network calls (only the one-time download of the free "Pandoc" tool if your machine doesn't
already have it).

**Is it paid?**
No — the code is in the public domain (CC0 license), and every tool it uses is free and open
source. See [`legal.md`](legal.md) and [`it-security.md`](it-security.md).

**Who verifies it's reliable enough for professional use?**
See [`it-security.md`](it-security.md) — automated tests, security analysis, and a verification
pipeline run on every code change.

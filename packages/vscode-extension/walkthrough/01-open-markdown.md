Ouvrez un fichier `.md` qui contient un bloc de code marqué `mermaid`, par exemple :

    # Rapport d'architecture

    ```mermaid
    graph TD
      A[Client] --> B[API]
      B --> C[Base de données]
    ```

Dès qu'un tel bloc est détecté, l'extension s'active automatiquement — aucun réglage requis.

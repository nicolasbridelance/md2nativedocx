Two links appear above every mermaid block:

- **⚙️ Export to Word** — converts the whole document (text, tables, every diagram).
- **Export this block only** — converts just this diagram into its own `.docx`.

A document with no diagram still gets an **⚙️ Export to Word** link at the top — full Markdown
export doesn't require one.

Other ways to trigger the same export: the status bar item at the bottom, right-click the file in
the Explorer or the editor, or the Command Palette (`Ctrl+Shift+P` → "md2nativedocx").

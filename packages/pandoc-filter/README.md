# @md2nativedocx/pandoc-filter

Pandoc Lua filter that converts ` ```mermaid ` code blocks into native OOXML/DrawingML fragments
via the [`@md2nativedocx/core`](https://www.npmjs.com/package/@md2nativedocx/core) engine. A
dependency of [`@md2nativedocx/cli`](https://www.npmjs.com/package/@md2nativedocx/cli), not meant
to be installed directly by most users.

Looking for the actual tool? See [`@md2nativedocx/cli`](https://www.npmjs.com/package/@md2nativedocx/cli)
or the [VS Code extension](https://marketplace.visualstudio.com/items?itemName=md2nativedocx.md2nativedocx).

Full project, architecture, and license details: <https://github.com/nicolasbridelance/md2nativedocx>

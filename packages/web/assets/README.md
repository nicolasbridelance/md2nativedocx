# Site assets

`og-image.png` (1200 × 630) is the picture shown when a link to the site is shared (LinkedIn, Slack,
Discord…), named by the page's `og:image`. It is a screenshot of the top of the page itself, in English,
taken in a 1200 × 630 viewport. Retake it when the hero section (`src/index.html`, `src/styles.css`)
changes visibly: build and serve `dist/`, then capture that viewport with any browser's device toolbar.
